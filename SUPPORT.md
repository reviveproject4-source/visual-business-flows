# Support

This project provides reusable workflow patterns, not organization-specific
implementation support or a guaranteed solution.

## Questions about using a workflow

1. Read the workflow's assumptions, open decisions, and implementation notes.
2. Open a GitHub issue if the question reveals a reusable documentation gap.
3. Include the relevant file path and a minimal, non-confidential example.

## Propose a new workflow

Use the **Propose a workflow** issue form. For substantial new domains,
discuss scope and intended audience before submitting a large pull request.

## Custom analysis

For organization-specific process analysis or developer-ready specifications,
contact [tri.raida.consulting@gmail.com](mailto:tri.raida.consulting@gmail.com).

Do not post credentials, customer data, private company documents, or other
confidential information in public issues.
