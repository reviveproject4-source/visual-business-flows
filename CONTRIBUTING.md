# Contributing to Visual Business Flows

Thank you for contributing to **Visual Business Flows**! We welcome diagrams, process patterns, and workflow improvements from developers, analysts, and operators worldwide.

---

## 📐 Contribution Guidelines

1. **Use Native Mermaid.js:** All workflows must be written in standard Mermaid syntax (`flowchart`, `sequenceDiagram`, `stateDiagram-v2`, `erDiagram`).
2. **Real-World Business Focus:** Focus on genuine operational problems (e.g., refunds, stockouts, dunning, reconciliation) rather than purely abstract theory.
3. **Include Explanations:** Every diagram file should include:
   * **Business Problem & Context**
   * **Actor & Entity Roles**
   * **Mermaid Code Block**
   * **Edge Cases & Failure Recovery Steps**

---

## 🚀 How to Submit a Pull Request

1. Fork the repository.
2. Create your branch: `git checkout -b feature/add-hotel-booking-flow`
3. Add your diagram under the appropriate domain folder.
4. Preview the diagram in GitHub or [mermaid.live](https://mermaid.live).
5. Open a Pull Request!
